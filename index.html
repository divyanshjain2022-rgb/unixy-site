How it works

From a phone recording to exam-ready notes — automatically.

A designated scribe uploads once. The whole class benefits. No website, no app, no new habits — just the Telegram group you already have.

Upload

A scribe drops the lecture audio, slides, or reading PDF into a private admin group. That's the entire workflow.

Understand

unixy transcribes the lecture — tuned for Indian-classroom English and Hinglish — and reads slides and scans with vision AI.

Compose

Frontier AI drafts structured notes tagged to your syllabus, capturing what the professor emphasised — the parts exams are made of.

Deliver

Notes land in the class group within minutes, pinned boards track deadlines and exam points, and everything becomes searchable.

Features

A full teaching assistant, staffed by AI, supervised by humans.

📝

Syllabus-tagged notes

Every note is mapped to your course's actual syllabus units, with the professor's emphasised points called out — not generic AI summaries.

🔍

Citation-strict Q&A

Ask /ask anything. Answers cite the exact lecture or reading they came from — and unixy refuses to answer when the material doesn't cover it.

📅

Deadlines that chase you

Assignments, moots, and internals live on a pinned board in IST with automatic 3-day and 1-day reminders. No calendar app required.

📂

Instant file recall

"/files unit 3" fetches every lecture, slide deck, and reading for that unit — months later, in seconds.

🤖

An agent you can @mention

The unixy Concierge answers questions, compiles exam-prep outlines, delivers files, and drafts class updates — conversationally.

🛠️

Self-correcting notes

Spotted an error? Reply /report. AI drafts the fix, a class admin approves it, and the note is corrected in place for everyone.

"In law, a made-up citation isn't a typo — it's malpractice. So unixy is built to never fabricate a case, section, date, or holding. If the class material doesn't support an answer, it says so."
✓

Grounded by construction. The AI can only cite sources it was handed — every answer carries its receipts.

✓

Refusal over guesswork. Thin evidence produces "I couldn't find this in the class notes" — never confident fiction.

✓

Humans hold the pen. Anything students see — a deadline, a correction, an announcement — is proposed by AI and approved by a class admin first.

Built on AWS

Every model that touches a student's notes runs on Amazon Bedrock.

Law-grade output needs frontier models, not the cheapest ones. Bedrock lets us put the strongest available model on each job — and keep every lecture inside one governed account.

Note generation Amazon Bedrock

  • Claude Opus — drafts the structured, syllabus-tagged note from a full lecture transcript, preserving what the professor emphasised.
  • Long-context reasoning is the difference between a summary and a note a student can revise from.

Q&A, vision & the agent Amazon Bedrock

  • Claude Sonnet — powers /ask, reads slide decks and scanned handouts, and runs the Concierge's tool-use loop.
  • Tool use is what lets the agent fetch files and draft updates instead of just talking about them.

Retrieval Amazon Bedrock

  • Cohere Embed Multilingual v3 — 1024-dimension embeddings that hold up across English and Hinglish lecture transcripts.
  • Cohere Rerank 3.5 — the precision step that makes "cite or refuse" workable rather than aspirational.

Around the models Supporting

  • AssemblyAI for transcription, tuned with per-course legal keyterms.
  • Postgres + pgvector for the corpus and vector index; Redis-compatible queues for the ingestion pipeline.
  • Python, containerised, deployed from CI — currently on a single small Linux host.

What credits change: compute is the cheap part — inference is the bill. AWS credits go directly into running Opus-class models on every lecture instead of rationing them, and into consolidating the pipeline, database and queues onto AWS alongside the models they already serve.
